# V0 screen contract

1. **Login**: email and password; invalid credentials show a generic error.
2. **Dashboard**: current organization and role; navigation to knowledge base
   and chat preview.
3. **Knowledge base**: placeholder upload/status layout for V3.
4. **Document status**: placeholder pending/ready/failed states for V3.
5. **Chat preview**: placeholder grounded-answer/source layout for V4.

Demo journey: an admin logs in, opens the knowledge-base screen, reviews the
planned upload flow, opens chat preview, and understands where grounded
answers and safe fallback will appear. No external integration is required.
